# Vision

> Stub. To be filled from the council report ([Conceiving the Roobotto Project](../Conceiving_the_Roobotto_Project-2026-10-16.html)), sections A (reframed vision and the bet) and H (opportunities).

Roobotto is a local, open-source stage manager for live bands. It estimates where the band is
in a song from audio, MIDI, and footswitch evidence, and drives production cues through a
deterministic, safety-gated cue engine. Machine learning supplies evidence; deterministic
code decides what fires.

The working summary lives in `implementation-plan.md` Section 1.
